# Background

The user is a solo founder running a portfolio of roughly a dozen projects at once, most of them unfinished. The immediate priority is getting products shipped into beta rather than perfecting them.

One live project is **Asymmetry** (asymmetria.io): a privacy-first, zero-knowledge encrypted "packet delivery" system, currently in pre-beta. It is explicitly not a wallet, custodian, or financial adviser, and its zero-knowledge core is safety-critical.

The guiding principle for every agent here: **bias toward shipping the smallest valuable beta, and fight scope creep relentlessly.**
